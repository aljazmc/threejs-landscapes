# Hull Breach

A small first person shooter in cyberpunk style in three.js.

| | Space commando | Aliens |
| --- | --- | --- |
| health | 500 | 300 |
| moving speed | 4 m/s | 4 m/s |
| attack | laser gun or grenade launcher | claws, 50 damage, at most every 1.2 s |

| Weapon | Damage | Between shots | Hits |
| --- | --- | --- | --- |
| 1 laser gun (default) | 30 | 0.5 s | only the first alien in the line of fire |
| 2 grenade launcher | 500 | 3 s | where the grenade hits: the alien hit takes all 500, every other alien within 9 m less, by its distance |

| Mouse / key | Action |
| --- | --- |
| mouse | look around (click into the view to capture the mouse) |
| W A S D, arrow keys | move |
| Space, left click | fire (hold to keep firing) |
| 1, 2 | laser gun, grenade launcher |
| Esc | pause to the main menu |

On a phone or tablet the game goes fullscreen and sideways where the browser allows it (not on iPhones):

| Touch | Action |
| --- | --- |
| left half | a joystick where the thumb lands: walk in any direction, slower when tilted less |
| right half | drag to look around |
| FIRE button | fire (hold to keep firing) |
| the weapon panels | choose the laser gun or the grenade launcher |
| II at the top | pause to the main menu |

The main menu has *Play*, *Save*, *Load* and *Language* (English, Deutsch, Polski, Slovenščina); the saved game and the language are kept in the browser's local storage.

```
yarn s:hullbreach    # dev server
yarn bp:hullbreach   # production build into dist/, three.js from esm.sh
```

## Sources

`src/index.ts` starts `src/game/main.ts` (the letterboxed 960x540 view, screens, save and load). `menu.ts`, `game.ts` (the commando, weapons, HUD), `ship.ts` (map, hull, props, lights; collisions, rays, paths), `alien.ts`, `fx.ts`, `gfx.ts`, `audio.ts`, `lang.ts`, `ui.ts` (the 2D layer and the bitmap font) and `res.ts` (loading).

The game keeps its own coordinates (Z up, left handed); `src/space.ts` converts them for three.js by mirroring Y. `src/lights.ts` makes three.js point lights fade as 1 / (constant + linear d + quadratic d²) and lights the ship with the 16 lights that shine brightest at the camera. Colors are blended as stored, without sRGB conversion.

## Resources

Everything in `src/res` is generated by the scripts beside `src`:

```
./project.sh graphics   # blender-scripts/ with Blender: the map, sprite sheets and GLB models
./project.sh audio      # fluidsynth-scripts/ with numpy and FluidSynth: sound effects and music
./project.sh font <font.fnt>   # pillow-scripts/font.py: the Pixel Operator font with č, š, ž, ą, ł...
```
